# Shift Note

iPhoneのカレンダーにある「シフト」の予定から、給与・勤務時間・年収を計算するアプリです。
Scriptable版（Shift Note・Shift Pay）をネイティブアプリにしたもので、ホーム画面・ロック画面のウィジェットも入っています。

## できること

| タブ | 内容 |
|---|---|
| 概要 | 次のシフト、今月の予想給与（勤務済み・これから）、勤務時間・日数・実質時給・深夜手当・交通費、前月比、これからのシフト |
| カレンダー | 純正カレンダーのような月表示。日付をタップするとその日のシフトと給与 |
| 年収 | 年収の見込み、月別グラフ、年収の壁（110万〜178万）までの残り、月ごとの明細。「働いた月」と「給料日の月」の集計を切り替え |
| 設定 | 読み込むカレンダーと予定の名前、時給（平日・土曜・日曜）、深夜割増、交通費、休憩、締め日と支給月、週の始まり |

### ウィジェット

| ウィジェット | サイズ |
|---|---|
| 次のシフト | 小・ロック画面（長方形・1行） |
| 今月の給与 | 小・中・ロック画面（長方形・1行） |
| 年収と年収の壁 | 小・中・大・ロック画面（長方形・1行） |
| シフトカレンダー | 小・中・大。長押し →「ウィジェットを編集」で期間を選べます（1週間・今日を真ん中／1週間・今日から／今週／2週間／1か月） |

給与の計算式は Scriptable 版と同じです（1分ごとに曜日別の時給と22時〜5時の深夜割増を足し、休憩は勤務時間全体から按分）。
シフトの予定は shifcon-sync（Scriptable）がカレンダーに書き込んだものをそのまま使います。

## IPA の作り方（Mac 不要）

`main` に push すると、GitHub Actions（`.github/workflows/ios.yml`）が自動でビルドします。手動で動かすときは **Actions** タブ →「iOS Build」→「Run workflow」。

1. 完了した実行を開き、下の **Artifacts** から `ShiftNote-unsigned-番号.ipa` をダウンロード
2. 普段使っている署名ツールで署名してインストール

ビルドの途中で、給与の計算が Scriptable 版と同じ金額になるかのテストも行います。

## 初期設定

1. アプリを開いて、カレンダーへのアクセスを許可
2. 「設定」タブで時給・深夜割増・交通費・休憩・締め日を入力（読み込むカレンダーは「すべてのカレンダー」のままで大丈夫）
3. ホーム画面・ロック画面にウィジェットを追加
4. ウィジェットを長押し →「ウィジェットを編集」で、アプリと同じ時給などを入力

ウィジェットとアプリは保存場所が別なので、時給などは両方に入力が必要です（attend と同じです）。

## 構成

```
Shared/           計算・カレンダー読み込み（アプリとウィジェットで共通）
ShiftNote/        アプリ本体（SwiftUI）
ShiftNoteWidget/  ウィジェット（WidgetKit）
ShiftNoteTests/   ユニットテスト
project.yml       XcodeGen の設定
```

年収の壁の金額は2026年分の目安です（`Shared/PayEngine.swift` の `IncomeWall.all`）。
